# Becoartes Tablet - Sistema de Cardápio Digital

Este projeto é o frontend do sistema de tablets para clientes do Becoartes.

## 📱 Configuração de Tablet (Modo Quiosque)

Para uma experiência profissional e segura no tablet (Android), recomendamos o uso do **Fully Kiosk Browser**.

### Configurações Recomendadas no Fully Kiosk Browser:
- **Start URL**: `https://tablet.becoartes.com`
- **Kiosk Mode**: Ativado (Bloqueia acesso ao sistema Android)
- **Fullscreen Mode**: Ativado
- **Keep Screen On**: Ativado
- **Launch on Boot**: Ativado
- **Disable Status Bar**: Ativado
- **Disable Home Button**: Ativado
- **Exit Kiosk with PIN**: Ativado (ex: 0040)

### Comandos Secretos (Busca do Tablet):
- `0044`: Força entrada em Modo Tela Cheia via navegador.
- `0040`: Força saída do Modo Tela Cheia.

### PWA (Standalone):
O sistema também suporta instalação como PWA. No iPad, use "Adicionar à Tela de Início" no Safari para remover as barras do navegador.
