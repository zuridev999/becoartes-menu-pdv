# Status público do Delivery

Decisão da Fase 4: o Delivery ainda não faz parte dos fluxos operacionais lançados.

- Produção deve permanecer com `publicStatus` diferente de `open`.
- A URL pública exibe somente o estado "Delivery ainda não lançado".
- Catálogo, carrinho, cadastro e pagamento ficam inacessíveis enquanto o gate estiver fechado.
- Abertura pública exige homologação dos smokes de entrega e pagamento, validação visual mobile e autorização explícita do responsável pelo Becoartes.

Esta decisão não remove o código em desenvolvimento nem os testes existentes; apenas evita apresentar um produto incompleto como disponível.
